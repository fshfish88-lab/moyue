# 墨阅 V1.7.4 · 阅读体验修复

- 文楷改为真实霞鹜文楷字体，分页测量、正文和设置预览共用字体；首次加载放在后台执行。
- 阅读设置分为常用与更多设置，按需显示；字号、亮度滑块拖动时使用局部状态，松手后保存，减少正文重排。
- 长章节分页按偏移索引查找当前页文本块；阅读会话内保留最多 3 组、合计不超过 200 万字符的分页缓存。正文、字体、字号、间距或阅读区域变化时重新计算。
- EPUB 正文使用 DOM 解析，保留标题、引用、分隔线、表格行、脚注正文及本地图片，支持无引号图片属性和完整 Unicode 实体。
- 包含 V1.7.3 网页多部分正文合并、目录分页补全和旧缓存升级修复。

保留原有 TXT 按章节读取、阅读位置保存、EPUB 包结构缓存及邻章预加载。小说全局搜索范围不变。

直接覆盖安装，无需卸载。内置完整文楷字体会增加安装包体积。

本轮没有实现完整 EPUB CSS 排版、脚注跳转、仿真翻页或备份恢复功能。实际测试范围与性能数据见[验证记录](https://github.com/fshfish88-lab/moyue/blob/main/docs/v1.7.4-verification.md)；模拟器结果不能代替真机表现。
