# V1.6.1 修复验收

2026-10-08，原签名 Release，versionCode 24，最低 Android API26。

## 原问题与修改

- 重复选中同一段文字更新原记录，保留笔记；重叠部分绘制最近修改的颜色，保留未覆盖部分。Markdown/PDF 的重叠色块也避免重复混色。
- 原生阅读器使用源位置对应的高亮范围，在文字行的字体高度内绘制，排除行距、空行、段落分隔和缩进空白。
- PDF 标注使用页面比例坐标，并跟随缩放、旋转与渲染事件同步更新，覆盖 PDF.js 延迟重绘期间的尺寸变化。
- 保留现有设置布局；缓存阅读配色，只在属性变化时更新系统栏、亮度、常亮和正文排版。延迟列表试验未带来首开收益，最终未采用。
