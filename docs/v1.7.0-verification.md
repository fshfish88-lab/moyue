# 墨阅 V1.7.0 书架升级验收

## 交付与使用

版本 1.7.0，versionCode 28，最低 Android 8.0 / API 26。正式 APK 使用原发布签名，可直接覆盖安装，无需卸载。

- 顶部切换全部书籍或自定义书架，独立选择想读、在读、读完及收藏；排序入口支持最近阅读、导入时间、书名、作者、进度。
- 格式、作者、多标签筛选放在筛选面板；格式和作者各自任意匹配，标签全部匹配，跨维度同时匹配。
- 长按书籍管理收藏、状态、多个书架和标签，并可补录系列信息。顶部集合菜单提供书架与标签的新建、重命名、删除。
- 多选可全选当前结果，批量收藏/取消收藏、调整状态、添加或移除分类、确认删除书籍。半选分类表示部分书籍已有该关系，未调整的分类保持不变。
- 分类删除仅移除关系；书籍删除明确列出数量和标题，确认后删除应用内副本、缓存、进度及标注，原导入文件保留。
- 旧书按进度初始化状态一次；状态此后独立管理，阅读进度变化不重新强制写成读完。收藏与状态互不覆盖。继续阅读卡片和封面网格保留。

## 证据与限制

验证设备为 API 36 模拟器；未执行物理手机或特定厂商系统分享面板验证。API 26 为构建最低要求，本轮未另启动 API 26 设备。

数据快照基线复用了上一版 V1.6.4 验收结束时的完整记录，本轮期间没有对原书执行阅读或修改。升级后和测试清理后均重新导出并比对；真实库原有书签和标注为空，非空位置/标注的兼容性由独立迁移样本验证。

旧 V1.6.0 全套仪器测试的 schema 2 → 4 前 5 项迁移检查通过，随后小说正文 FTS 的旧断言失败：V1.6.3 已将小说搜索范围改为目录。该旧整套未标记通过；本次使用现行 SearchScopeInstrumentation 的 12 项回归验证现有搜索合同。首轮多选界面自动化读取到布局变化前的缓存坐标，刷新 UI 自动化缓存后 12 项真实触摸检查通过，应用选择实现未为此更改。

证据保存在 `过程文件文件夹/测试证据/2026-10-11-V1.7.0书架升级`，包括原始仪器输出、前后数据快照、进程重启记录、界面截图和签名校验记录。机器汇总见交付目录 `verification-summary.json`；GitHub 发布后对提交、4 个附件摘要和匿名下载的验证记录单独保存在 `release-verification.json`。
