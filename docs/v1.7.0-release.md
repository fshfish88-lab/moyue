# 墨阅 V1.7.0

书架管理升级，保留封面网格与继续阅读卡片。

- 阅读状态分为想读、在读、读完，可在长按菜单或多选模式中手动调整。旧书首次升级按进度初始化，之后进度变化不覆盖手动状态。
- 收藏独立保存，可与状态、自定义书架、格式、作者和标签组合筛选。
- 自定义书架支持新建、重命名、删除，一本书可同时加入多个书架。
- 标签支持新建、重命名、删除和多标签管理。所选标签全部匹配；同一维度的格式、作者多选匹配任意一个，跨维度同时匹配。
- 排序支持最近阅读、导入时间、书名、作者和阅读进度。最近阅读与导入时间倒序，进度从高到低，书名与作者升序；未知作者置后，排序相同时按书籍 ID 保持稳定。
- 顶部提供集合、状态与排序入口，格式、作者、标签位于筛选面板。筛选与排序保存在 DataStore，返回书架和重新启动后恢复。
- 长按书籍管理收藏、状态、书架、标签及系列信息；系列可补录或留空移除。
- 多选支持全选当前筛选结果，批量收藏/取消收藏、状态调整、书架与标签添加/移除、书籍删除。部分分类成员采用半选状态，未调整的关系保持不变。
- 删除分类只删除分类关系，保留书籍、源副本、阅读进度和标注。删除书籍仍需明确确认，并清除应用内副本、缓存、进度和标注；原始导入文件不受影响。

版本号 1.7.0，versionCode 28。Room schema 3 → 4 使用增量迁移，沿用原发布签名，可直接覆盖安装，无需卸载。继续支持 V1.6.4 的系统单文件与多文件分享导入。
