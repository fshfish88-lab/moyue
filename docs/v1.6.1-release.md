# 墨阅 V1.6.1

修复高亮与阅读设置的使用问题。

- 再次选中同一段文字会更新标注颜色，保留已有笔记；重叠部分使用最近修改的颜色，其他部分保持原色。
- TXT/EPUB/缓存网页的高亮只绘制在文字行内，保留行间和段落空白。
- PDF 高亮随页面尺寸同步缩放，避免放大过程中等待重绘导致色块漂移。
- 阅读配色按实际颜色变化计算，保留现有设置布局；避免打开设置时重复更新配色、系统栏、亮度、常亮状态和文本布局属性。

Android 8.0（API 26）及以上；versionCode 24。沿用墨阅原发布证书，请直接覆盖安装，不要卸载旧版。数据库仍为 schema 3，书籍、进度、书签与笔记继续保留。

验收：146 项 JVM 测试、Release lint/构建、54 项数据检查、20 项交互检查及 5 项高亮/设置专项检查通过。实际像素检查确认新颜色生效、行间留白；PDF 在延迟重绘的缩放阶段仍与页面坐标对齐。原有 6 本书及数据逐项一致，最终 Release 冷启动通过。

设置性能：API36 模拟器连续 4 次打开约 0.64～0.86 秒，采样帧间隔 P95 为 33 毫秒（修复前 49 毫秒）；仍观察到首开短暂停顿。未连接物理设备，真机性能需要复测。
