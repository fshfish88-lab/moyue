# V1.6.3 阅读点击与全局搜索验收

2026-10-09，原签名 Release，versionCode 26，最低 Android API 26。修复范围为阅读页顶部/底部工具栏、滚动与分页点击、全局搜索。

## 问题与修复

- 工具栏原先在每次显示时重新创建控件。现在保留组合，只动画更新位置和透明度；隐藏时不参与触摸和无障碍访问。正文 TextView、文字对象和排版对象在开关工具栏时保持不变。
- 可选择的原生正文会消费短按，父级 Compose 无法收到点击。增加短按转发，保留长按选字与拖动。滚动模式左、中、右区域统一开关工具栏。
- 分页模式独立处理：左侧上一页、中央工具栏、右侧下一页。使用固定视口坐标，短按翻页前释放原生文本焦点，防止旧页面的焦点可见性请求把页面拉回。点击直接落到目标页，滑动继续使用原来的拖动/惯性翻页；滑动进行中忽略点击翻页。
- 全局搜索包含所有书籍/文档名称、小说目录、Markdown/PDF 文档正文。TXT、EPUB、WEB 小说正文不再索引或搜索；已有小说正文结果立即被查询过滤，随后原子替换为目录索引。目录更新自动同步，阅读进度和封面变化不触发重建，小说目录索引不读取原始小说文件或网络正文。
- 名称、目录、正文分栏各自查询；目录结果定位章节起点，不伪造正文高亮。保留标注中心及已有笔记、书签。

## 性能证据与限制

在同轮空闲模拟器对照中，两版均已加入原生短按转发，仅对比工具栏重建/保留：EPUB 封面首次响应 399→188 毫秒，简介首次 235→119 毫秒，两者帧间隔 P95 均从 83 降至 49 毫秒。

最终版本：EPUB/TXT 正文中央点击 111–226 毫秒，封面/简介 116–163 毫秒；这些是注入点击到工具栏状态响应的耗时，不代表整段动画完成时间。最终各场景帧间隔 P95 为 49 毫秒。

独立“更多阅读设置”面板的 4 次打开耗时为 1586/1520/1318/1531 毫秒，未全部达到 1500 毫秒测试阈值，帧间隔 P95 99 毫秒、最大 616 毫秒。未把这项失败计为通过。延迟列表试验没有稳定收益，已撤回并保留原设置布局；采样显示仍有系统窗口创建、组合和渲染开销，不能宣称所有设置弹窗均无卡顿。

未连接物理设备，未做真机覆盖安装或帧率验收；PDF 本轮验证页文本搜索，未重新验证完整 PDF 解析流程。此报告记录发布前验收，发布状态以 GitHub 发行页为准。
