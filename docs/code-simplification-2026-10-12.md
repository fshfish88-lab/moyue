# 墨阅代码逻辑精简与优化

基准：`2fca008`，V1.7.0 / versionCode 28。本轮保持数据库 schema、阅读位置格式和界面操作不变，源码留在当前工作区，未提交或发布到 GitHub。

本文记录 2026-10-12 优化验证包的阶段结果。上述优化随后纳入 [V1.7.1](v1.7.1-release.md)；后续书架样式调整及正式版本验收见 [V1.7.1 验收记录](v1.7.1-verification.md)。

## 实际改动

| 模块 | 改动与目的 |
| --- | --- |
| ReaderViewModel | 滚动章节和位置合并为一次状态发布；相同章节、段落、字符偏移和进度直接返回；一次滚动连续变化共用一个保存协程，最后一次变化稳定 300 ms 后写入；退出立即保存，导航取消旧待保存位置 |
| ReaderScreen | 将像素滚动映射到逻辑阅读位置后去重；预加载只观察接近窗口末尾的状态，与位置上报分开；用索引查找滚动条目；保留正文与工具栏隔离 |
| EPUB | 会话缓存包结构，源文件、解包目录、container、OPF、导航文件的路径/存在状态/长度/修改时间变化使其失效，派生缓存重建时清空；先发布当前章节，相邻章节由界面生命周期协程预加载，导航可取消预加载 |
| 标注 | 标注变化时统一排序、解析 JSON 并按章节分组；章节内容变化时验证源文本哈希、预计算按段落索引的高亮范围；每个 TextView 仅映射自己的文本段；保留重叠颜色覆盖、跨段高亮和临时跳转高亮 |
| MoyueApp | 书籍、书架、书架偏好订阅只在书架页面存在；更新状态只在设置页面订阅；详情页读取数据期间保留加载状态；合并网址导入和浏览器纯净模式的导入处理，保留协程取消传播 |
| 搜索目录查询 | ChapterDao.observeCatalog 从全部章节字段缩到 ID、标题、序号，减少无用数据读取，不改变表结构或索引内容 |
| 清理 | 删除 ReaderBlock、仅供它使用的字体/行高辅助逻辑；删除从未产生非空预览的网页确认界面和回调；移除源码、测试均未引用的 navigation-compose |

没有为消除几段重复代码而合并 PDF 与 Markdown 的 JS 通信，也没有大面积拆分页面或引入架构框架。

## 构建与运行验证

- JVM：156 项测试通过，0 失败、0 错误。新增重复位置/跨章单次发布、正文优先加载及 EPUB 缓存复用/失效检查。
- Debug、Release、仪器测试包构建成功；Release lint 为 0 Error/Fatal、17 Warning，包含现有 WebView 特性检查、依赖版本和 KTX 建议。
- 实际 Release / API 36 模拟器：核心逻辑 33 项；真实 EPUB 正文分页 16 项、滚动 18 项；标注颜色及设置 7 项；分享导入 41 项；现行搜索范围 12 项通过。网页及大目录场景另有 36 项有效布尔断言通过；虚构域名真实联网刷新明确跳过。
- 核心运行检查确认：1000 次重复位置不产生新状态或保存；20 次位置变化共用同一工作协程，只保存最后位置；返回立即保存且不会再次延迟保存；导航取消相邻章节加载。
- 真实 EPUB 工具栏切换：分页和滚动的采样帧间隔 P95 均为 16 ms。该检查验证本轮交互，无主线程完整追踪或真机对照，不能据此宣称全部卡顿已解决。

覆盖安装与全部测试结束后，比对 12 张业务表的完整行、2 个源文件 SHA-256、两份偏好文件 SHA-256，共 14 个快照分区全部一致；测试新增书籍全部清理。旧测试将五个原先省略的默认文档/图片偏好写入了文件，已按测试前 SHA-256 精确恢复原始字节，临时恢复代码已移除。冷启动成功（TotalTime 1428 ms）。

首轮 Debug 的旧分页测试在长按后失去测试 Activity，后续翻页失败。原版 V1.7.0 Release 与最终优化 Release 的同一套 16 项检查均通过；该 Debug 初次失败日志仍保留，没有计入通过结果。

大目录网页测试复现了后台搜索目录订阅的 CursorWindow 读取崩溃，原查询读取全部章节字段。改用三个实际需要的字段后，大目录投影可完整读取，现行搜索范围 12 项重新通过。

旧网页测试还暴露了测试本身的过时提示断言、同名测试书误选和虚构域名联网问题。修正提示断言、给 UI 测试书唯一名称并缓存正文；虚构域名的真实联网刷新另行标记跳过，注入网络失败时目录全部行及 1828 章数量保留的断言仍运行。生产目录加载器未为测试改动，失败诊断日志保留。

## R8 与资源核查

使用独立 Gradle 初始化脚本试验代码及资源压缩，另外保留 JavascriptInterface 方法；没有改变仓库默认的 Release 压缩配置。

| --- | ---: |

体积下降约 49.5%。压缩后 DEX 从 9,928,093 降至 1,942,014 字节。两种包均含 766 个 assets 条目；主要第三方资源没有裁剪。入口实际引用 PDF.js worker、CMaps、标准字体、WASM，以及 Vditor 的 Lute、高亮和 KaTeX，保留这些动态依赖。

R8 包仅完成构建与包内容核查，尚未完成压缩产物下 PDF、Markdown、图片/漫画等全部阅读引擎回归，因此本次交付沿用默认未压缩 Release。压缩配置和 JS 桥保留规则参考 [Android 官方优化说明](https://developer.android.com/topic/performance/app-optimization/enable-app-optimization) 与 [优化问题排查](https://developer.android.com/topic/performance/app-optimization/troubleshoot-the-optimization)。
