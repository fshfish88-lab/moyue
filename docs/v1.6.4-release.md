# 墨阅 V1.6.4

从微信、文件管理器等应用分享文件时，可在系统分享列表选择「墨阅」。支持 TXT、EPUB、Markdown（MD）、PDF、JPG/JPEG/PNG/静态 WebP 图片、CBZ 和纯图片 ZIP。

支持单个或多个文件；收到后依次复制并导入书架，显示现有导入完成提示。多文件中某个文件失败时继续处理其他文件，并显示成功数量和失败原因。Office、音视频等尚未接入的格式会显示格式提示。

兼容发送方使用 application/octet-stream 等通用类型，以及仅通过 ClipData 提供文件的情况。导入任务在 Activity 重建时继续，重建不重复导入；墨阅已经打开时再次分享仍可接收。文件须由发送方提供可读取的 content URI；权限不足时显示错误。

网页链接分享继续填写「导入网页」地址。数据库结构、既有书架、源文件和阅读记录沿用原版。安装时直接覆盖安装，不要卸载。

本版本使用原签名 Release APK；真机及具体发送应用的分享面板需在对应设备上验证。
