# 墨阅 V1.6.4 文件分享接收验收

2026-10-11。原签名 Release，versionCode 27，最低 Android API 26。

## 改动

- 系统单文件和多文件分享入口支持通用 MIME 类型，包括发送方标为 application/octet-stream 的文件。
- 从 EXTRA_STREAM 或 ClipData 读取临时授权的 content URI，获取文件名称；没有扩展名时按明确 MIME 类型补齐。复用原有导入器，复制到墨阅内部后解析并保存书架。
- 支持 TXT、EPUB、Markdown、PDF、JPG/JPEG/PNG/静态 WebP、CBZ 和纯图片 ZIP。尚未支持的格式及读取权限问题沿用错误提示。
- 多文件依次导入，单个失败后继续处理并汇总成功数量和失败原因。
- 已打开时再次分享由同一个 Activity 接收；导入任务保存在 ViewModel 中，Activity 重建不重复导入。网页分享继续填写原有网页地址输入页。
- 数据库结构、阅读引擎和现有导入格式规则保持原版。

- Release lint：0 错误、0 严重错误、14 警告。差异格式检查通过。
- API 36 模拟器安装交付的原签名 Release，41 项分享检查全部通过。独立测试发送 APK 使用自己的 UID 和私有 ContentProvider，授予临时读取权限，验证跨应用实际读文件。
- 14 项系统目标查询覆盖单文件/多文件及文本、EPUB、PDF、Markdown、图片、ZIP、通用文件类型。旧版分享 PDF 时系统返回 No activities found，新版解析到 com.moyue.reader/.MainActivity。
- 实际导入 11 个测试文件，覆盖冷启动 TXT、已打开时 EPUB/PDF/Markdown/PNG/CBZ/图片 ZIP、无扩展名文本、仅 ClipData、多文件，以及部分失败的批次。检查文件已复制到墨阅内部。
- 验证已打开时复用 Activity、重建不重复导入、不支持的格式无残留书架条目、缺少 URI 授权时显示错误、部分失败后继续导入，以及网页链接仍填入原界面。
- 从 V1.6.3 覆盖升级前后，已有 2 本书籍、源文件 SHA256、阅读进度、文档状态、书签和标注快照完全一致。分享测试后清理本轮创建的测试内容，再次确认快照一致。
- APK 原发布证书、v2/v3 签名和 zipalign 检查通过。设备安装 APK 的 SHA256 与交付 APK 一致；冷启动 Status ok / COLD，MainActivity 在前台。

## 产物与范围

成品位于 `成品文件夹/墨阅-V1.6.4/`，包括可直接覆盖安装的 APK、源码 ZIP、SHA256、验证报告及机器可读校验摘要。安装时不要卸载；已有书籍无需重新导入。

证据位于 `过程文件文件夹/测试证据/2026-10-11-V1.6.4分享文件/`，最终分享日志为 share-import.txt。构建日志为 build-v164-share-verified.log、build-v164-share-unit-sample.log 和 build-v164-share-sender.log，复核脚本为 verify_v164.py。早期缓存/沙箱和测试发送端的失败日志留存，未计为通过。

本轮未连接物理设备，未直接验证微信或截图中手机的具体分享面板；模拟器证明系统目标匹配和跨应用文件读取、导入流程。本报告记录发布前验收；GitHub 发布及公开下载校验结果见成品目录 release-verification.json。
