# 墨阅 V1.7.1

优化阅读器内部逻辑，调整书架选择与状态筛选的显示形式。

- 书架使用方块按钮横向选择全部书籍和自定义书架；阅读状态改为下拉列表，收藏可独立叠加。保留原来的上下布局、书架与标签管理、排序及组合筛选。
- 滚动位置按章节、段落和字符位置去重，一次位置变化只发布一次状态；连续滚动共用保存任务，返回时立即保存进度。
- 缓存 EPUB 包结构，源文件或包信息变化时失效；先显示当前章节，相邻章节异步预加载，导航时可取消。
- 标注预先按章节、段落索引，减少每个文本块重复解析；保留原生文本选择、高亮颜色覆盖和跨段标注。
- 缩小书架与设置页面的数据订阅范围，删除未使用的渲染代码和依赖。
- 搜索目录只读取实际使用的字段，修复大目录场景下后台查询的 CursorWindow 读取崩溃。

版本 1.7.1，versionCode 29，Android 8.0 / API 26 及以上。沿用原发布签名，数据库仍为 schema 4。请直接覆盖安装，不要卸载，已有书籍、阅读进度和标注继续保留。

R8 仍未默认启用，本次没有裁剪 PDF.js、Vditor 等动态资源。验证范围及限制见 [验收记录](v1.7.1-verification.md)。
