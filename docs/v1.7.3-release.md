# 墨阅 V1.7.3 · 网页章节分页修复

- 正文区分“下一页”和“下一章”，将同一章的多个网页按顺序合并，在下一章边界停止。
- 目录支持 `/书号_页号/` 形式的同级分页，跨页提取、按章节网址去重；有章节总数时校验是否漏页。
- 旧目录会重新识别；旧正文缓存按阅读需要补全，保留原始 HTML、章节 ID、阅读进度和书签。离线时保留可用旧缓存并提示重试，补全失败不会标记完成。
- 分页循环、请求失败及超过页数上限时不保存新的不完整正文。

升级方式：直接覆盖安装，保持联网后重新打开网页书籍。也可在目录中点击“刷新目录”。

实现参考：[Legado 正文分页](https://github.com/CCSSNE/legado/blob/master/app/src/main/java/io/legado/app/model/webBook/BookContent.kt)、[Legado 目录分页](https://github.com/CCSSNE/legado/blob/master/app/src/main/java/io/legado/app/model/webBook/BookChapterList.kt)。参考的是分页遍历、去重和下一章边界处理方式；继续使用墨阅原有的网页解析与浏览器会话，不引入 Legado 规则引擎。

验证：通用离线样例覆盖目录跨页、正文两页及三页合并，以及阅读进度和旧缓存兼容。
