# 墨阅 V1.6.0

统一标注、摘录管理与全局搜索。

- 正文长按选字，添加彩色高亮或笔记；图片/漫画支持位置书签和笔记。
- 新增摘录中心，可按书籍、类型、颜色筛选，编辑或删除记录、返回原文、导出 Markdown。
- 书架新增全局搜索，检索书名、作者、本地正文、摘录和笔记；正文索引在应用运行期间后台建立，可继续未完成部分或重建。
- 适配 TXT、EPUB、已缓存网页、Markdown 和 PDF，支持原文定位及标注显示。
- 数据库增量升级，保留原有书籍、阅读进度和旧书签。请直接覆盖安装，不要卸载旧版。

Android 8.0（API 26）及以上；versionCode 23。安装包使用既有墨阅发布证书签名，下载后可用 SHA256.txt 校验。

已验证：142 项 JVM 测试、Release lint/构建、54 项模拟器数据检查和 19 项交互检查通过；原签名 V1.5.4 覆盖升级后，6 本原有书籍、源文件哈希、进度、文档状态和旧书签保持一致。最终签名 Release 冷启动通过。

限制：文本选择限当前页或段落，PDF 限单页；扫描 PDF 暂不支持 OCR。网页只搜索已缓存正文；加密 PDF 搜索解锁后已加载的页面。正文首次索引需要时间。没有执行物理设备验收。书架集合与标签不在本版范围。
